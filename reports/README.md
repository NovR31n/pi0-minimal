# Reports

This directory contains versioned experiment reports and small summary tables.
The main public result is documented in
[`2026-08-13_student_v3_formal_500.md`](2026-08-13_student_v3_formal_500.md),
with its predeclared checkpoint-selection and validation protocol in
[`2026-08-13_student_v3_checkpoint_gate.md`](2026-08-13_student_v3_checkpoint_gate.md).

Large videos, checkpoints, datasets, caches, and raw rollout files are stored
outside Git and referenced by experiment ID and SHA-256 where licensing and
size permit.
